# 录音自动转写模块设置页

## 目标

在现有 LSPosed 模块 APK 内加入一个设置页，让用户查看兼容状态并控制自动转写策略，不另建独立 APK。

## 页面

页面展示模块版本、录音机版本和兼容状态。它提供以下项目：

- 自动处理总开关；
- AI 摘要开关；
- “遵守原应用条件（Wi-Fi 且充电）”开关；
- 固定显示的“转写并行数：3”；
- “立即扫描”按钮。

默认启用自动处理和 AI 摘要，关闭原应用条件限制。三并发为模块固定策略，不在页面提供可变配置。

## 配置与数据流

设置页将配置保存在模块自己的私有偏好设置中。模块 APK 提供一个仅暴露必要读写操作的 ContentProvider：录音机进程中的 Xposed Hook 通过 Provider 读取最新配置，页面写入配置后下一轮扫描立即生效。页面的“立即扫描”通过模块的 Provider 请求录音机 JobScheduler 运行现有自动任务。

Hook 只在 `com.coloros.soundrecorder` 的已验证版本 `16.17.8` 生效。页面显示不兼容状态时不启用这些 Hook，避免录音机更新后因内部 API 改动而崩溃。

## 行为

自动扫描时，总开关关闭则不启动任务；“遵守原应用条件”开启时，保留录音机原有的 Wi-Fi、充电和空闲条件，关闭时继续绕过这些条件。自动转写使用原应用任务队列并最多同时启动三条。每条完成后带 AI 摘要状态交给原应用摘要服务；模块不修改摘要服务的并发策略。

## 公开发布

发布物为一个正式签名的 APK，既是 LSPosed 模块也是设置应用。酷安说明必须写明安装流程：安装 APK、在 LSPosed 启用模块并勾选录音机作用域、打开设置页确认兼容状态。它要求 Root 和 LSPosed，不能作为无 Root 的普通录音转写应用使用。

## 验证

单元测试覆盖默认配置、配置读取以及原应用条件开关的决策。构建后验证 APK 有启动 Activity 和 Provider；安装到手机后验证页面可打开、版本显示正确、修改开关后重新启动录音机仍加载模块，并能强制执行自动 Job。
